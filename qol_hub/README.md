# QOL Hub (Godot 3)

Adds a **QOL** tab next to AssetLib. It lists every plugin in
https://github.com/machinegirlxoxo/Godot-3-QOL-Plugins and installs the one you click into `res://addons/<plugin>/`.

## Setup
1. Copy `addons/qol_hub` into your project's `addons` folder.
2. Project > Project Settings > Plugins > enable **QOL Hub**.
3. Open the **QOL** tab, hit Install on a plugin, then tick **Enabled**.

New plugins pushed to the repo (any top-level folder containing a `plugin.cfg`) show up automatically after Refresh.
